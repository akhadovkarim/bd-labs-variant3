# Базы данных — лабораторные работы. Вариант 3

**Тема варианта:** система, описывающая порядок получения водительских прав.
**Выполнил:** Ахадов Каримжон Уткир угли, группа 223-322.

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `ЛР1/БД 3НФ` | Реляционная модель в 3НФ: `lr1_bd.sql` (22 таблицы), `lr1_data.sql` (тестовые данные), `lr1_bd.mwb`, ER-диаграмма |
| `ЛР1/БД DataVault` | Модель Data Vault: `lr1_bd_dv.sql` (14 хабов, 16 линков, 23 сателлита), `lr1_dv_load.sql` (загрузка из 3НФ), `lr1_bd_dv.mwb`, диаграммы |

## Порядок запуска (MySQL 8.0)

```sql
SOURCE ЛР1/БД 3НФ/lr1_bd.sql;
SOURCE ЛР1/БД 3НФ/lr1_data.sql;
SOURCE ЛР1/БД DataVault/lr1_bd_dv.sql;
SOURCE ЛР1/БД DataVault/lr1_dv_load.sql;
```
